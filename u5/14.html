'ㅂ' 소리가 덧나는 말

  • 벼 + 씨 → 볍씨
  • 해 + 쌀 → 햅쌀
  • 메 + 쌀 → 멥쌀
  • 조 + 쌀 → 좁쌀

'ㅎ' 소리가 덧나는 말

  • 수 + 닭 → 수탉
  • 암 + 닭 → 암탉
  • 머리 + 가락 → 머리카락
  • 안 + 밖 → 안팎
  • 살 + 고기 → 살코기

그래서 '수닭', '머리가락'이라고 쓰면 틀려요. 소리 나는 대로 '수탉', '머리카락'으로 씁니다.
