# 말과 글 수첩 — 국어 5-2

초등 5학년 2학기 국어 차시별 복습 사이트. 읽기 전용 참고서형.

<https://sikke12632.github.io/5-2korean/>

국정 국어 지도서를 학생이 읽을 수 있는 말로 다시 쓴 것이다.
수업은 교실에서 교과서로 하고, 이 사이트는 그 뒤에 혼자 확인할 때 본다.

## 페이지를 손으로 만들지 않는다

**차시 데이터(JSON) → 빌드 스크립트 → 사이트**

HTML은 건드리지 않는다. JSON을 고치고 다시 빌드한다.

```
python build_gugeo.py            # lessons/ → 저장소 루트
python build_gugeo.py --check    # 학생 화면에 '지도서'가 남았는지 검사
```

파이썬 3만 있으면 된다. 설치할 패키지 없음.

## 구조

```
lessons/gugeo-5-2/units.json     8단원 52차시 목차 (정렬 순서 포함)
lessons/gugeo-5-2/about.json     선생님 안내 페이지 내용
lessons/gugeo-5-2/u1/04-06.json  차시 하나 = 파일 하나
build_gugeo.py                   빌드 스크립트 (CSS·과제 3칸도 여기 들어 있다)
schema.md                        JSON 필드 정의 — 새 차시 쓰기 전에 읽을 것

index.html                       빌드 결과. 첫 차시로 보낸다
teacher.html                     빌드 결과
u1/*.html                        빌드 결과
```

빌드 결과 HTML은 커밋한다. GitHub Pages가 그대로 서빙한다.

## 차시 추가하기

1. `lessons/gugeo-5-2/<단원 id>/<차시코드>.json` 을 만든다
2. `python build_gugeo.py`
3. 커밋 · 푸시

목차(`units.json`)는 건드리지 않는다. 52차시가 이미 들어 있고,
JSON이 없는 차시는 목차에 흐린 글씨로 남아 링크가 걸리지 않는다.

빌드는 스키마·필수 필드·차시 코드·금지어를 검사하고, 하나라도 걸리면 멈춘다.

## 규칙

- **화면에 나가는 쪽수는 교과서만.** 지도서 쪽수는 HTML 주석으로만 남긴다
- **지도서 원문에 없는 내용을 만들지 않는다.** 채울 게 없으면 그 항목을 비운다
- **교과서에 있는 활동을 과제로 반복하지 않는다**
- 입력칸·자동채점·점수·순위 없음. 읽기 전용
- 모범답안을 통째로 주지 않고 **답의 모양**을 보여 준다 (오픈북 대응 + 저작권)
- 과제 3칸 문구는 전 차시 고정. 데이터가 아니라 템플릿에 있다

## 폴더 이름은 ASCII로

`u1`, `reading`, `media` 처럼 쓴다. 한글 폴더명은 zip·드라이브 이동에서 깨진다.
화면에 뜨는 단원 이름은 `units.json` 의 `title` 에서 나오므로 영향 없다.

## 저장하지 않는 것

로그인, 이름 입력, 점수, 진도 — 전부 없다. 서버로 보내는 것도 없다.

## `_source/`

지도서 원문(교육부 저작)이라 저장소에 올리지 않는다 (`.gitignore`).
차시를 쓸 때 필요하므로 `국어5-2_차시자료.zip` 을 각 컴퓨터에서 풀어 둔다.
